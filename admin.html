Conectar el panel

Esto se hace una sola vez, en esta computadora.

Hace falta una clave que le da permiso al panel para actualizar la web. Se genera en GitHub:

  1. Abrí esta página (pide iniciar sesión).
  2. En Repository access, elegí Only select repositories y marcá El-jaial.
  3. En Permissions → Repository permissions, poné Contents en Read and write.
  4. Generá la clave y pegala acá abajo.
Repositorio y rama

La clave queda guardada sólo en este navegador y nunca se sube a la web. Si esta computadora la usa otra persona, mejor no guardarla acá.
